## 📘 Algoritmo e Lógica de Programação – 1º Ano
Exercícios desenvolvidos no Portugol Studio / Portugol Dev

Este repositório reúne todos os exercícios realizados durante meu 1º ano de Ciência da Computação, nas disciplinas:

Algoritmo e Lógica de Programação I (1º bimestre)

Algoritmo e Lógica de Programação II (2º bimestre)

As atividades foram feitas sob orientação do professor Fábio, utilizando o Portugol Dev (Portugol Studio) para praticar lógica, algoritmos e estruturas fundamentais de programação.

## 🧩 Objetivo do Repositório

Centralizar, organizar e documentar todos os exercícios práticos de lógica desenvolvidos no primeiro ano da faculdade, permitindo:

Revisar e reforçar conceitos de lógica de programação

Registrar evolução no aprendizado de algoritmos

Servir como material de consulta e estudo futuro

Ajudar outros estudantes iniciantes em Portugol

## 📚 Conteúdos Abordados
### Algoritmo e Lógica de Programação I

Conceitos iniciais:

Variáveis e tipos primitivos

Entrada e saída de dados

Operadores aritméticos e lógicos

Estruturas condicionais (se, senao)

Introdução a algoritmos e fluxogramas

### Algoritmo e Lógica de Programação II

Conteúdos intermediários:

Estruturas de repetição (para, enquanto, facaenquanto)

Vetores e matrizes

Subalgoritmos e funções

Problemas clássicos de lógica

Aplicação de algoritmos mais estruturados
